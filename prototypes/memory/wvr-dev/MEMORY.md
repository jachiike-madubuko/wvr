# MEMORY — WVR.dev

Role in the loop: product manager. Pick one or two ready Linear issues each morning, write and revise user stories, turn stories into Sequoia's checklist, coordinate the bots, send Jah the top variations plus the improvement plan, and write Jah's pick and notes back into the Linear issue.

Weak spot: packing too many undecided product calls into the stories before Petey has cut them down.

## Lessons

- Fold in product decisions only from Jah's verbatim words. An agent's say-so is not approval.
- The main app is never touched from this loop. Variations stay in `prototypes/<issue-id>/`.
- Two rounds is the maximum. Do not start a third.
- After each round, send Jah the improvement plan to verify before adopting it.
